# Fortune in a Pot

One kind, funny fortune for the houseplant on the windowsill — a single line of 119 characters, written for the make.fun bounty "Fortune in a Pot".

> Soon the morning sun will visit your windowsill first, and you will grow one brave leaf to make the neighbours jealous.

## Run

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt`.
